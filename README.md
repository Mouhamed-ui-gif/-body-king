# سيد الجسد BODY KING

تطبيق تدريب كاليستنكس احترافي — مبني بالكامل على **Node.js بدون أي مكتبات خارجية**،
مع كوتش ذكاء اصطناعي (Google Gemini)، نظام نقاط وتحديات، ومتجر شخصيات قصصية.

- **المؤسس:** محمد غناي (Mohamed Ghannai)
- **المستوى المستهدف:** فوق المتوسط — متقدم
- **مدة الجلسة:** 45 – 75 دقيقة
- **الأهداف:** القوة، بناء العضلات، وتقوية الاتصال العصبي-العضلي

## المزايا

- 🇲🇦 واجهة عربية كاملة (RTL) بتصميم داكن احترافي على الهاتف والحاسوب
- 📅 برنامج أسبوعي من 5 جلسات (ضغط / سحب / مركز / مهارات / تحمل) + يومان راحة
- 📈 نظام نقاط ذكي: الطول/الجودة/الوقت/السلسلة/الإتقان + مكافآت الشخصيات
- 🏆 26 إنجازًا + مستويات ونقاط تجربة (XP)
- 🦸 متجر شخصيات (9 شخصيات) تُشترى بالنقاط وتُرتدي للحصول على مكافآت
- 🤖 كوتش ذكاء اصطناعي يجيب بالعربية ويتابع تقدمك (Gemini)
- 📊 صفحة إحصائيات: 7 أيام، سجلات شخصية، تمارين الأسبوع
- 🔔 يعمل دون إنترنت بعد أول تحميل (PWA)

## التشغيل

```bash
cd /home/mouh/kalistenix

# 1) ضبط المفاتيح (أنشئ .env من المثال ثم ضع مفتاح Gemini):
cp .env.example .env

# 2) تشغيل الخادم:
node server.js
```

افتح في المتصفح: `http://localhost:8080`

### على الهاتف (نفس شبكة الواي فاي)
اعرف عنوان جهازك ثم افتح `http://<IP-الجهاز>:8080` من الهاتف
(مثال: `http://192.168.1.5:8080`). أو أضف 8080 لإعدادات "التطبيقات المصغرة" في موجه.  

إيقاف الخادم:
```bash
fuser -k 8080/tcp
```

## الإعدادات (ملف .env)

| المتغير            | الوصف                     |
|--------------------|---------------------------|
| `GEMINI_API_KEY`   | مفتاح Google Gemini        |
| `GEMINI_MODEL`     | النموذج (افتراضي: gemini-3.6-flash) |
| `PORT`             | المنفذ (افتراضي: 8080)     |
